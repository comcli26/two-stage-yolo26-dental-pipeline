## Models used in the final integrated pipeline

The geometric-association stage (`notebooks/03_geometric_association/pipeline_asociacion_geometrica.ipynb`) loads exactly two models:

- **Detection:** `modelo_deteccion_final.pt` (= `yolo26m-det_best.pt`)
- **Segmentation:** `modelo_segmentacion_final.pt` (= `yolo26s-seg_best.pt`)

If you only want to reproduce the final end-to-end pipeline (Tables 15–17 and the qualitative figure), you only need these two files.

## Regenerating the weights from scratch

All weights can be regenerated by running the notebooks in `notebooks/01_tooth_segmentation/` and `notebooks/02_caries_detection/` in order, after completing the data-preparation stage (`notebooks/00_data_preparation/`). Training was done on Google Colab (Tesla T4 GPU); the downstream geometric-association evaluation (notebooks/03_geometric_association/) was run on a separate NVIDIA L4 runtime. See `docs/environment.md` for exact library versions, hardware per stage, and hyperparameters.
